# AFPAP — Institutional Brochure / Code Edition

موقع **HTML + CSS فقط** لعرض البروشور المؤسسي بالعربية، وتصديره PDF بقياس A4. لا توجد قاعدة بيانات ولا محرر ولا ملف JavaScript مستقل ولا تحتاج إلى Node.js.

## التشغيل

1. فك الضغط.
2. افتح `index.html` في Chrome أو Edge.
3. انقر **Download PDF**. في نافذة الطباعة اختر **Save as PDF** و**Paper size = A4** و**Margins = None** و**Scale = 100%**، وفعّل **Background graphics**. أوقف Headers and footers إذا ظهر الخيار.

> نافذة الطباعة مقصودة: هي الطريقة الأبسط والأكثر ثباتًا في هذا المشروع. المتصفح لا يصدر ملفًا تلقائيًا دون تدخل إلا بحلول برمجية إضافية لا يحتاجها المشروع.

## أين تعدّل؟

| ماذا تريد تغييرَه؟ | الملف والمكان |
|---|---|
| كل النصوص والعناوين والأسعار وبيانات التواصل | `index.html`، ضمن الصفحة المعنية |
| الهوية والألوان | `style.css` تحت `:root` (أول الملف) |
| الخط العربي | `style.css` تحت `--font-body` و `--font-display` |
| تخطيط الصفحات والمسافات وأحجام العناصر | `style.css` تحت عنوان الصفحة المطابقة |
| صورة الغلاف | `style.css`، ابحث عن `.cover-photo` ثم `background-image` |
| صورة المؤسسات | `index.html`، ابحث عن `institution-team-demo.webp` |
| صورة الدكتورة | `index.html`، ابحث عن `founder-image-placeholder` |
| أغلفة الكتب | `index.html`، ابحث عن `book-cover` |

## استبدال صورة الدكتورة

ضع صورتها الحقيقية باسم `founder.jpg` داخل `assets/`، ثم **استبدل محتوى** العنصر الذي يحمل `class="founder-image-placeholder"` بهذا العنصر فقط:

```html
<div class="founder-image-placeholder">
  <img src="assets/founder.jpg" alt="الدكتورة سوسن الصدفي المكني">
</div>
```

الصور التوضيحية الموجودة لأشخاص داخل مشاهد التدريب ليست صورًا موثّقة من نشاطات الأكاديمية؛ يمكن استبدالها بصور حقيقية قبل إرسال البروشور رسميًا.

## استبدال أغلفة الكتب

ضع `book-1.jpg` و`book-2.jpg` و`book-3.jpg` داخل `assets/`. في كل عنصر `book-cover` استبدل محتواه الحالي بصورة، مثل:

```html
<div class="book-cover">
  <img src="assets/book-1.jpg" alt="الغلاف الأصلي لكتاب عربية المستقبل">
</div>
```

النصوص الموجودة حاليًا على نماذج الأغلفة عناصر تصميمية مؤقتة وليست نسخًا من الأغلفة الحقيقية.

## إضافة أو حذف صفحة

كل صفحة عبارة عن قسم في `index.html` يبدأ بـ:

```html
<section class="page ..." id="..."> ... </section>
```

- للحذف: احذف هذا القسم كاملًا.
- للإضافة: انسخ أي قسم والصقه بين الصفحات وعدّل نصه والصنف `class` إن أردت تصميماً جديدًا.
- **أرقام الصفحات تلقائية** وليست مكتوبة يدويًا. عدد صفحات PDF يتغير بحسب أقسام `section.page` الموجودة.
- يُنصح أن تختبر PDF بعد إضافة نص طويل، لأن مساحة صفحة A4 ثابتة وقد يتجاوز النص التصميم.

## النشر على Vercel

أبسط طريقة: ارفع مجلد المشروع إلى GitHub ثم استورده من Vercel عبر **New Project > Import**. اختر `Other` كـ Framework Preset، واترك إعداد البناء فارغًا. تأكد أن `index.html` في جذر Repository. لا تحتاج إلى Environment Variables أو بناء Frontend.

## ملاحظة عن الخطوط

الخطوط المستخدمة في CSS هي **Amiri** للعناوين و**IBM Plex Sans Arabic** للنصوص. يتم طلبها من Google Fonts إذا توفر الإنترنت، مع خطوط بديلة يختارها المتصفح عند عدم توفر الاتصال. لا توجد ملفات خطوط داخل المشروع.
